# Minecraft Real Places Builder

Небольшая CLI-программа, которая помогает выбрать реальное место и получить базовый план постройки в Minecraft:

- выбор места (Эйфелева башня, Статуя Свободы, Биг-Бен, Колизей);
- выбор масштаба;
- расчёт размеров в блоках;
- стартовые `/fill` команды.

## Запуск

```bash
python3 minecraft_places_builder.py
```
